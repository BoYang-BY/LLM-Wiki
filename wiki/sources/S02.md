## Evidence

**原文定位**　SUMMARY & USAGE LICENSE、DETAILED DESCRIPTIONS OF DATA FILES（u.data、u.item、u1.base–u5.test）。

原始 README 記錄 943 位使用者、1,682 部電影和 100,000 筆 1 至 5 分評分。u.data 的每列包含使用者 ID、物品 ID、評分與時間戳。u.item 可用多個二元類型欄描述同一部電影。原始發行包提供 80/20 訓練測試檔與五折安排。

**適用範圍**　入口頁用約數。精確規模以 README 為準。樣本依原始清理條件保留至少評過 20 部電影的使用者，不宜當成真正的新使用者樣本。
